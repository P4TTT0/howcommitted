# AGENTS.md

Rules for contributors and AI coding agents. Detail lives in `docs/`; this file only states what must not be broken.

## Core principle

COMMITS != PRODUCTIVITY. Committed shows rhythm and habits, never value. Canonical statement: [docs/product.md](docs/product.md#core-principle).

## Project state

Design phase. No code exists yet. Do not scaffold beyond what a task asks for.

## Structure rules

Planned tree: [docs/architecture.md](docs/architecture.md).

1. `src/domain/` is pure: no React, no fetch, no Next.
2. `src/github/` never reaches the browser; it starts with `import "server-only"`.
3. `src/playback/` owns the single clock; components never animate on their own clock.
4. Tests are colocated: `streaks.ts` next to `streaks.test.ts`.

## Never

Full list: [docs/design.md](docs/design.md).

- Copy that judges developers ("best", "most productive", "winner") or invented percentiles.
- Gradients, glow, blur, confetti, emoji, generic icon sets, or fonts other than the two chosen.
- Autoplaying sound, unskippable animation, or one sound per commit.
- Labeling the contribution calendar as commits, or inventing private contribution dates.
- Exposing the GitHub token to the browser, or pooling tokens from multiple accounts.
- Preview deploys sharing production credentials: they use their own token and cache.

Not in the MVP (deliberate scope decision): Three.js/WebGL, a database, a global state library.

## Spelling

Brand **Committed**, domain **howcommitted.com**, repo `P4TTT0/howcommitted`. Always double "t".

## Workflow

- Everything goes through a pull request. No direct pushes; `main` is protected.
- Conventional Commits; the PR title uses the same format. Squash merge only.
- Never add AI attribution: no "Generated by", no `Co-Authored-By` trailers, no tool credits in commits, PRs, or files.
- Branch names and PR expectations: [CONTRIBUTING.md](CONTRIBUTING.md).

## Harness

- Do not add `CLAUDE.md`, `.claude/CLAUDE.md`, or `CLAUDE.local.md`. Claude Code reads `AGENTS.md` only when none of them exist; adding one silently stops it loading.
- CI (Biome, tsc, Vitest, Playwright) is the real guardrail.
- Add skills only after a task repeats 3+ times.
- Spec-driven planning only for big pieces (playback engine, GitHub data pipeline).
- No custom subagents, MCP servers, or complex hooks.
