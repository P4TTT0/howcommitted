# AGENTS.md

Rules for contributors and AI coding agents. Detail lives in `docs/`; this file only states what must not be broken.

## Core principle

COMMITS != PRODUCTIVITY. Committed shows rhythm and habits, never value.

- Describe habits ("night owl", "longest streak"), never merit ("best", "most productive", "winner").
- Versus is a game, not a ranking.
- The final screen and share card keep this visible line: "Commits are not productivity. This is rhythm, not value."

## Project state

Design phase. No code exists yet. Do not scaffold beyond what a task asks for.

## Folder structure (planned)

```
src/app/        Thin Next.js routes only
src/domain/     Pure TypeScript types and metrics
src/github/     Server-only GraphQL client, queries, cache
src/playback/   Single clock driving GSAP and Tone.js (sound/ inside)
src/features/   timeline, stats, versus
src/ui/         Shared presentational components
public/sounds/  .ogg with .mp3 fallback
e2e/            Playwright tests
.github/        Workflows and templates (planned)
```

Rules:

1. `domain/` is pure: no React, no fetch, no Next.
2. `github/` never reaches the browser. It starts with `import "server-only"`.
3. `playback/` owns the single clock. Components never animate on their own clock.
4. Tests are colocated: `streaks.ts` next to `streaks.test.ts`.

Details: [docs/architecture.md](docs/architecture.md).

## Prohibitions

Full list and reasons: [docs/design.md](docs/design.md). Never add:

- Gradients, glow, neon, glassmorphism, blur
- Soft generic cards, diffuse shadows, left-border accent cards
- Emoji or generic icon sets
- Fonts other than Big Shoulders and Martian Mono
- Confetti
- Pie, 3D, or dual-axis charts
- Invented percentiles or value judgments about developers
- Tap-through vertical stories or "Your year in commits!" copy
- Autoplaying sound, unskippable animation, generic spinners
- One sound per commit, or default synths
- Three.js/WebGL, a database, or a global state library

## Glossary and spelling

- Brand: **Committed**. Domain: **howcommitted.com**. Repo: `P4TTT0/howcommitted`. Always double "t".
- Solo: one user. Versus: two to five users. There is no mode toggle.
- Scene: one stage of the animation (year blocks, cumulative line, heatmap, language mosaic, big numbers).
- Poster: the final screen with Share, Challenge someone, Replay.

## Workflow

- Everything goes through a pull request. No direct pushes; `main` is protected.
- Branches: `feat/`, `fix/`, `docs/`, `chore/` prefixes, short-lived.
- Conventional Commits. The PR title uses the same format.
- Squash merge only.
- Never add AI attribution: no "Generated by", no `Co-Authored-By` trailers, no tool credits in commits, PRs, or files.
- Contributor workflow: [CONTRIBUTING.md](CONTRIBUTING.md).

## Environments

- Each PR gets a Vercel preview deployment; it acts as staging.
- Previews use their own GitHub token and a separate Upstash database or key prefix. Never reuse production credentials in previews.
- Rollback for production is Vercel instant rollback.

## Data honesty

- Count only real commits. Never label the contribution calendar as commits; it includes all contribution types.
- Compare summed daily commits with the official total. If they differ, show the real total with a notice.
- Private contributions show only as "+N private". Never invent their dates.
- Language data is languages of owned repositories, not per-commit. Label it that way.
- Never invent percentiles or comparisons that the data does not support.
- Never pool tokens from multiple accounts.
- Never expose the GitHub token to the browser.
