## Gesture samples

Three more Kenney (Kenney.nl) packs, all Creative Commons Zero (CC0 1.0). Same treatment: the `.ogg` files are the originals, renamed, with an added mono 44.1 kHz `.mp3` copy.

- Interface Sounds: https://kenney.nl/assets/interface-sounds
- UI Audio: https://kenney.nl/assets/ui-audio
- Impact Sounds: https://kenney.nl/assets/impact-sounds

| Files | Pack | Original name | Gesture and role |
|-------|------|---------------|------------------|
| `pop` | Interface Sounds | `drop_002` | `pop`: a small block appears |
| `fill-tick` | Interface Sounds | `tick_001` | `fill`: accelerating ticks while a bar loads |
| `stair` | Impact Sounds | `impactGlass_light_001` | `stair`: one step of a low-to-high sequence |
| `count-tick` | Interface Sounds | `click_003` | `count`: ticks while a number climbs |
| `count-close` | Interface Sounds | `confirmation_002` | `count`: the closing hit when it settles |
| `hover` | UI Audio | `rollover2` | `hover`: pitch encodes the value pointed at |
| `click` | UI Audio | `click1` | `click`: any press |
